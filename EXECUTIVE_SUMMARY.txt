ISSUE: Connect button appears non-functional - clicking it does nothing

================================================================================
THE PROBLEM IN 30 SECONDS
================================================================================

When users click "Connect" after entering credentials:
  ✗ No error message appears
  ✗ No success message appears
  ✗ Page doesn't navigate
  ✗ Application appears frozen/broken
  ✗ Nothing happens (silent failure)

ROOT CAUSE:
  Token mismatch between client and server due to server restarts.
  Error response is generated but not displayed to the user.

LIKELIHOOD: 90% confidence this is the actual issue


================================================================================
WHY IT HAPPENS
================================================================================

SCENARIO:
1. User loads http://127.0.0.1:9000
   → Flask generates a unique token for the page
   → Token embedded in HTML: <meta name="app-token" content="xyz123...">

2. Flask server restarts (auto-reload in development mode)
   → NEW unique token generated
   → Old token becomes invalid

3. User fills form and clicks "Connect"
   → JavaScript sends old token in request header
   → Server rejects with 403 Forbidden
   → Error message generated: "Refresh the app."

4. Browser receives 403 response
   → Error handling code should display message
   → BUT: Error message is not visible to user
   → User sees: "Nothing happened"
